# Python Week 5 – Object-Oriented Programming (OOP)

## About the Project

This repository contains my Week 5 Python Internship Assignment focused on Object-Oriented Programming (OOP).

The assignment demonstrates the fundamental OOP concepts through practical Python programs.

## Tasks Completed

### Task 1 – Classes and Objects
- Creating classes and objects.
- Defining attributes and methods.
- Displaying student information.

### Task 2 – Constructors
- Understanding the `__init__()` constructor.
- Initializing object attributes.
- Creating objects with different values.

### Task 3 – Inheritance
- Understanding parent and child classes.
- Using `super()` to access the parent constructor.
- Demonstrating inherited methods.

### Task 4 – Polymorphism
- Implementing the same method name in different classes.
- Demonstrating different behaviours.

### Task 5 – Encapsulation and Abstraction
- Using private attributes.
- Implementing getter and setter methods.
- Creating abstract classes and methods.
- Demonstrating banking operations.
